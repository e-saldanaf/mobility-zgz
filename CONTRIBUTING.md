# Contribuir al proyecto Mobility Zaragoza

Gracias por querer contribuir. Por favor, sigue estas pautas básicas:

1. Forkea el repositorio y crea una rama con prefijo:
   - feature/mi-nueva-funcionalidad
   - fix/correccion-descripcion

2. Estilo de commits
   - Mensajes breves: "feat: añadir README de instalación" o "fix: corregir typo"
   - Referenciar issues: "fix: corregir X (#12)"

3. Tests
   - Añadir tests unitarios para cambios funcionales.
   - Ejecutar: `pytest`

4. Pull Request
   - Incluir descripción del cambio y pasos para probar.
   - Seleccionar reviewers y etiquetar el tipo de cambio.

5. Revisión de código
   - Mantener funciones pequeñas y con docstrings.
   - Actualizar documentación si cambian interfaces públicas.

6. Seguridad
   - No subir claves ni datos sensibles.
